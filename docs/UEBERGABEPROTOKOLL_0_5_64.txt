B. URSACHE
- Der letzte Assert in scripts/local-file-tool-selftest.php
  verlangte wörtlich den seit 0.5.61 alten optionalen Skills-Hook:
  if ($augmentSkills) $userPrompt = coreui_skills_augment($userPrompt);
- Der korrekte Code seit 0.5.62 lautet:
  $userPrompt = coreui_skills_augment($userPrompt, $augmentSkills);
- Diese Aenderung ist beabsichtigt: Pflicht-Skill Werkzeuge bleibt
  auch bei fokussierten Dateiaufrufen aktiv, optionale Pakete werden
  ueber $augmentSkills=false ausgespart. scripts/skills-selftest.php
  kontrolliert genau diesen Vertrag bereits.
- Die anderen vier Teilbedingungen des lokalen Datei-Selbsttests
  wurden im aktuellen Handler ebenfalls nachgewiesen. Kein Beleg
  fuer eine defekte Datei-Implementierung aus diesem Testfehler.

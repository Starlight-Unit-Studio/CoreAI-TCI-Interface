Goal
- An account's CoreAI portrait is also its image-generation self-portrait reference.
- The canonical Mara photo is images/mara_winter.jpg. Custom upload wins for that account; removal restores the original.
- Per-account assistant display names are applied to personal UI while Mara Thorne's canonical identity remains unchanged.
- Fictional roleplay changes clothes/scenery/persona acting, not the TCI identity. Requests for unrelated subjects never inherit her reference portrait.

Architecture
- api/profile_store.php resolves account-scoped assistant media through a database record.
- api/image_gen.php distinguishes [BILD:] from [BILD ICH:] and [BILD GROSS ICH:], routes an optional opaque reference to the local image service.
- tools/image/image_service.py validates an internal "default" or "custom:<32 hex>" token and passes a locally resolved file as sd-cli -r; no user-supplied path is honored.
- api/chat.php and api/console_composer_intent.php carry the selected account nickname and recover explicit self-portrait requests when an older generic marker is used.
- UI strings use the account's chosen name or neutral wording, preserving technical IDs and stored event names. Model files, pinned weights, installer and database migrations are unchanged.
- Browser asset keys for modified scripts are content-derived SHA-256 digit strings.

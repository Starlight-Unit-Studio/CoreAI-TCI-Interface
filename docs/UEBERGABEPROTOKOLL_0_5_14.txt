2. REPARATUR
Die aktuelle Ausgangsbasis in GitHub ist 0.5.13.
Dieses Update ist 0.5.14, kein Rueckbau auf 0.5.12.
- docker/php/Dockerfile prueft pdo_mysql unmittelbar beim Build.
- scripts/install.sh prueft den frisch gebauten Container separat,
  erneuert danach ausschliesslich php und web in eigenem Compose-Projekt
  und prueft den dann laufenden PHP-Container nochmals.
- scripts/preflight.sh und scripts/preflight-native.sh verwenden
  extension_loaded() statt php -m | grep -Fxq (pipefail).
- scripts/pdo-mysql-installer-selftest.py prueft diese Vertraege offline.
- Fehlende PDO-Unterstuetzung bleibt ein Blocker.

VERIFIZIERTE OLLAMA-EINSCHRAENKUNG
- Ollama hatte 2026 experimentelle Bildgenerierung auf macOS; nach v0.32.5
  wurde diese entfernt. Die standardmaessige Linux-Ollama-Installation kann
  derzeit ein x/flux2-klein-Bildpaket als Core im Inventar halten, ohne Bilder
  durch eine native API zu generieren.
- Bildpaket und Bildgenerator sind nicht austauschbar. Existing sd.cpp FLUX.2
  Klein Q8_0 ist weiterhin der einzig aktivierbare Standard-Renderer.
- Die Ollama-Quelle zeigt und installiert nur Bild-Core-Familien, die Auswahl
  als aktiver Renderer bleibt ohne nachgewiesene Engine blockiert.

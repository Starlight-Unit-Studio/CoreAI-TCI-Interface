COREAI: TCI INTERFACE // CHANGELOG 0.7.97
Date: 2026-11-18

Visible public agent workflow
- Project agents can write one explicitly public progress sentence before each
  genuine tool call, using the already validated COREUI_PUBLIC_PROGRESS form.
  The assistant describes the next action or a verified finding in its own
  words. This is visible assistant content, NOT private chain of thought.
- Commentary survives server events and is live-streamed and saved to the
  existing Work Events timeline. A filtered fallback remains available if the
  model fails to produce a safe note.
- Verified process/server/command results receive state-derived short
  explanations, without raw worker output, secrets or unsupported success
  claims. Process start and exit code do not declare a whole project done.
- Long project agent commands without a fixed maximum now fold into the
  correct technical action group in the UI. Folded groups show actual confirmed
  action counts and failure counts, keeping public notes visible outside them.
- Work-event UI and PHP agent-loop selftests check public text, confidential
  data suppression, tool outcome semantics, streaming-style transitions and
  continuing automatically to the next step.

Tests and rollout
- Existing Compose and Native Preflight paths already register the expanded
  agent-loop and work-events UI regression tests.
- Requires actual Android and live CoreAI server verification after merge.
- The changes affect public commentary, not the protected model reasoning
  channel, model queue, model configuration, sandbox permissions or guest quotas.
- Separate issue #349 remains the place for recovery after a true runner abort.

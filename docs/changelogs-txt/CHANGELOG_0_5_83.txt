CoreAI: TCI Interface 0.5.83 - 29.10.2026
- Eingabefeld springt nach dem Senden auf eine Zeile zurueck (jede Textaenderung per Code passt die Hoehe an; vorher 128 px, jetzt 32 px).
- Legende "Core-Stufen" nur mit Maras TCI-Stufen; fremde Modelle (z. B. gpt-oss) nur noch im Core-Menue unter den festen Stufen.
- Core-Menue laedt die Ollama-Liste schon beim Oeffnen des Chats.
- Modell-Freigaben: Maras Cores fuer alle; Modelle ausserhalb von CoreAI nur fuer den Inhaber und Konten, denen er sie unter Admin Core > Benutzer (Spalte CORES) freigibt; Pruefung bei Liste, Wahl und Laufzeit; Migration 020 (stu_user_model_access).

"Update starten" zeigt allen "Bitte auf Neustart warten" und laedt neu, sobald CoreAI zurueck ist.
- Ablauf auf dem Host (scripts/coreai-updater.sh per systemd): Datenbanksicherung (var/backups, 5 Staende), offizielles setup.sh des Commits, Worker-Neustart, optional systemctl restart ollama. Die Weboberflaeche legt nur eine Anfragedatei ab (Inhaber, CSRF, Audit).

- PHP-Sitzungen in var/php_sessions: nach einem Update bleibt man angemeldet.
- Einmalig: das Update auf 0.5.83 selbst noch mit dem Setup-Einzeiler.

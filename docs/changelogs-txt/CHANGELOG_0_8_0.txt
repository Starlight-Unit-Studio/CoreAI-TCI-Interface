COREAI: TCI INTERFACE // CHANGELOG 0.8.0
Date: 2026-11-19

- Fast private console SSE stream now recognizes the already-authorized
  project-file, process and version markers before committing a final reply.
  The same check applies after a response continuation.
- A clear first-person promise to read a named project file, such as
  "Ich lese mir jetzt style.css durch", is no longer mistaken for a completed
  action. The safe agent loop runs ONLY the project-scoped read-only tool.
- The same recovery works after a completed tool, so the project loop can
  read the next file instead of ending on an intent sentence.
- All project ownership, file path validation and access restrictions remain
  in the existing dispatcher; no write/execute/browser permissions inferred.
- New regression assertions for read promises, safe rejection and automatic
  continuation. Stream image-tool test adapted without removing image checks.
- Version, Changelog, Preflight and numeric browser cache fingerprints updated.
- Requires real installed CoreAI and Android/desktop end-to-end verification.

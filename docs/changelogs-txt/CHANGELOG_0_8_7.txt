Operator observations

Changes

2. Preserve the explicit local-Core switch unload to avoid retaining all variants in CPU RAM.
3. Keep conversation context distinct from model residency: a loaded model is not a substitute for sending/rehydrating the original chat history after worker restart.
4. Do not use an old completed plan to automatically rebuild a file-backed project on later user requests. Account-owned project with at least one file uses its incremental pfile workflow instead.
5. Add explicit normal/compact project instructions: a new page such as blog.html extends saved files and current message, not the historical project spec.
6. Regression checks for keep_alive 15m -> -1, numeric conversion, all three Ollama payload routes, previous Core unload, and existing project file write preserving index.html.
7. Both native and Docker Preflights now have a source-sync regression rule for both fixes.

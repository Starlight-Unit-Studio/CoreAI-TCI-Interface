GOAL
Enforce one system-wide image reference consistency layer for EVERY reference image, instead of a weak Mara-only portrait instruction. The standard is applied in the PHP generator after the user/model has selected the existing image tool, before the prompt is sent to the pinned FLUX.2 service.

ARCHITECTURE
- api/image_reference_consistency.php: pure mode classifier and prompt composer.
- api/image_gen.php: includes the reusable helper and uses it for canonical self portraits, private personal avatars, and account-scoped multiple uploaded image references.
- api/chat.php: retains a user-specified style-only decision through Vision and subsequent tool execution. Ordinary picture-only turns stay unchanged.
- Both Docker and native preflights require/run scripts/image-reference-consistency-selftest.php; existing image selftest expectations adjusted.

REFERENCE MODES
- identity: humans and recurring characters; preserve individual facial geometry (eyes/nose/lips/jaw/cheekbones/hairline), natural anatomy and recognizable body proportions. No fixed height for every character.
- subject: objects, vehicles, animals, products or generic unknown subjects; preserve silhouette, geometry, textures, materials, colors, markings and identifying traits, including faces when the input happens to depict people.
- style: ONLY on an explicit instruction to use references as artistic style. Copy the requested color palette, brushwork, lighting and mood without copying unrelated pictured subjects.
- multi reference: keep subjects distinct, no swapping or blending faces/markings.

Prompt budget: use full block if it fits; otherwise compact block; if still long, preserve the beginning and ending of the scene description.

KNOWN LIMITS
FLUX.2-klein is a generative model. Reference input plus prompt guidance improves but cannot guarantee pixel-exact facial or bodily identity. Accurate identity lock might require a stronger identity-consistent editing pipeline in the future. This patch does not replace the model or add a new image worker.

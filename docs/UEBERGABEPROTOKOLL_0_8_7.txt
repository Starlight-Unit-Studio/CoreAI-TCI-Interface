Confirmed source facts
- api/config.php default COREUI_EMBER_KEEP_ALIVE was 15m (STU_EMBER_KEEP_ALIVE); chat.php helper already fell back to -1 only when no constant existed.
- Core preload and both Ollama chat routes already sent ember_keep_alive() at request top level; a single default change and numeric normalization therefore cover all paths.
- Explicit switch in api/core_preload.php sends keep_alive 0 to old resident local model.
- api/console_build_intent.php always recovered original user request from latest completed Markdown plan, even when the same project chat already contained saved source files. That could regenerate old requested site and ignore later blog.html instruction.
- api/project_file_tools.php supports actual pfile_read, pfile_edit, pfile_write with revisions, preserving unrelated files.

Resolution
- Default -1 (numeric) for active local Ollama Core; default can be deliberately overridden by operator configuration.
- Bypass old full-project build intent selection for account-owned project chats containing existing project files; normal agent tools use the latest message.
- Preserve first-time plan-to-build for new/file-empty projects; do not alter the model's Modelfile, context-size choice, or shared queue.
- Record and validate with offline selftests plus Preflight contract and versioned changelog.

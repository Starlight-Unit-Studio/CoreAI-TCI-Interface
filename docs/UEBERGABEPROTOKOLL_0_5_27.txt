  modellgeneriertes Python als erstes Werkzeug ausgefuehrt.
- Das Modell liefert ausschliesslich HTML-Quelldaten; CSS und JS inline.
- CoreUI normalisiert standardmaessig auf index.html, sofern kein
  einzelner anderer HTML-Name angefordert wurde.
- Vollstaendiges HTML5 und keine separaten lokalen Asset-Abhaengigkeiten
  sind Voraussetzung. Ungueltige Quellen gehen nicht zum Python-Worker.
- Maximal ein zweiter, serieller Modellversuch bei fehlerhaftem HTML.
- Der bisherige vertrauenswuerdige eigene Python-Writer erstellt
  die Datei und optional ein bestaetigtes ZIP in der Sandbox.
- Die echten Downloadkarten bleiben kontobezogen und manifestgeprueft.
- Mehrere gewuenschte Quelldateien bleiben im bestehenden ZIP-Pfad.
- Lokal Qwen bleibt auf dem historischen [PY]-Coding-Weg.
- Nicht-Qwen Cloud sowie lokales Gemma erhalten den HTML-Sonderpfad.
- Allgemeine Python-Tools sind weiterhin nutzbar und unmodifiziert.
- E.M.B.E.R.-Modellaufrufe bleiben streng seriell.

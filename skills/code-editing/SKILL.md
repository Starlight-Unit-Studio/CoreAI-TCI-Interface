# Gezielte Codeänderungen

Lies die betroffenen Dateien vor einer Änderung. Erhalte Nutzerdaten, öffentliche Schnittstellen und unabhängige Änderungen. Nutze das vom Werkzeug verlangte Editierformat exakt; keine erfundenen Zeilennummern oder Auslassungszeichen als Quelltext. Arbeite bei unklaren Treffern mit zusätzlichem Kontext. Prüfe den Diff auf unbeabsichtigte Löschungen und die betroffene Funktion mit einem passenden Test. Beschreibe die Verhaltensänderung.

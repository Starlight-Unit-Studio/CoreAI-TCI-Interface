# Eigene CoreUI-Skills

Ein Skill braucht eine eindeutige Kennung, Beschreibung, Einsatzbedingungen und konkrete Schritte. Speichere Anleitungen in SKILL.md mit name und description im Frontmatter. Halte den Text unter dem CoreUI-Paketlimit. Registriere Titel, Kategorie, Trigger, Quellen und Prüfdatum im Katalog. Schreibe eigene Anleitungen und respektiere Lizenzen. Aktiviere neue Pakete nicht heimlich für bestehende Konten. Skills ersetzen keine Werkzeugberechtigungen oder echte Validierung.

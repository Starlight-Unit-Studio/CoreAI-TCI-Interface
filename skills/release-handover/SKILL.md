# Release und Übergabe

Unterscheide kompatible Änderungen, Fehlerkorrekturen und Schnittstellenbrüche anhand der Projektkonvention. Halte sichtbare Versionsangaben und Changelog konsistent. Dokumentiere Basis, Branch, Commit, Änderungen, Prüfungen, Grenzen und nächsten Schritt. Nenne geplante Tests nicht als bestanden. Nach jedem CoreUI-Merge ein neues TXT-Protokoll anlegen; alte Protokolle erhalten. GitHub Actions bleiben gemäß Projektvorgabe aus.

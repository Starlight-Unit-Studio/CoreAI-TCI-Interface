# Fehleranalyse

Halte Soll, Ist, Auslöser und die erste relevante Fehlermeldung fest. Trenne Beobachtung von Vermutung. Verkleinere den Fall, prüfe Eingaben und Zustandsübergänge, ändere eine begründete Ursache. Fange erwartete Fehler gezielt; ein pauschales Verschlucken von Exceptions ist keine Reparatur. Wiederhole den ursprünglichen Fehlerfall und einen benachbarten Erfolgsfall. Ohne Laufzeitbeleg nur eine vermutete Behebung melden.

# ZIP und Dateiauslieferung

Erzeuge zuerst alle Projektdateien, danach das Archiv. Verwende relative, sichere Archivpfade ohne Elternverzeichnis-Sprünge. Prüfe Inhaltsliste, nicht leere Dateien und ZIP-Integrität; CRC allein beweist keine funktionierende Anwendung. Vergleiche lokale Referenzen mit vorhandenen Einträgen. Eine README soll Start und Abhängigkeiten erklären. Melde den Download erst, wenn das Werkzeug die Datei bestätigt hat. Keine erfundenen Links.
